Cómo sumar una oferta o tu perfil

Hay un formulario para cada caso, o podés mandar un pull request copiando una tarjeta de esta página. Antes de publicar, repasá las reglas.

  1. Elegí qué querés sumar. Una oferta laboral o tu perfil abierto a propuestas.
  2. Completá los datos. Para una oferta: puesto, modalidad, contrato y cómo postularse. Para un perfil: rol, nivel, qué buscás y tus links.
  3. Lo revisa el equipo. Cuando se aprueba aparece acá. Las ofertas se cierran solas en su fecha y los perfiles se pueden actualizar o sacar cuando quieras.
Completar el formulario Hacerlo con un PR

Para empresas y equipos

  • La oferta tiene que decir modalidad, tipo de contrato y cómo postularse.
  • Nadie paga por postularse ni por aparecer. Si piden dinero, no se publica.
  • No se piden datos sensibles (DNI, domicilio) en el primer contacto.
  • Sin requisitos que excluyan por edad, género u otras condiciones personales.

Para personas

  • Todo lo que publiques es público y lo indexan los buscadores.
  • Compartí solo el contacto que quieras mostrar. Mejor GitHub o LinkedIn que teléfono o domicilio.
  • Cada perfil muestra cuándo se actualizó. Los que llevan mucho sin cambios se retiran.
  • Podés pedir que saquen tu perfil cuando quieras.
